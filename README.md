## Git & Collaboration Workflow

All development was completed using feature branches.

The team followed this workflow:

```text
main
  │
  ├── feature/member-feature
  │
  ├── feature/member-feature
  │
  └── feature/member-feature
          │
          ▼
      Pull Request
          │
          ▼
         main
```

Team members were required to:

1. Create a feature branch.
2. Work only on their assigned feature.
3. Commit their changes to their branch.
4. Push the branch to GitHub.
5. Open a Pull Request.
6. Review and merge the Pull Request.
7. Keep the `main` branch protected from direct development commits.
